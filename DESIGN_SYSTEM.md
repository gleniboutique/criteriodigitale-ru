# Design System — Living System

## Concept

INTELLECTUAL EDITORIAL × SYSTEMS CARTOGRAPHY × ITALIAN MATERIALITY

The site should feel like a high-quality intellectual magazine, a systems map and a tactile European object at the same time.

## Colors

- Warm Ivory: #F3EFE7
- Paper: #FBFAF7
- Graphite / Ink: #1D2224
- Deep Petrol: #153D3A
- Oxidized Copper / Terracotta: #A9644C
- Grey Sage: #7C8982
- Lines: #D8D2C7

Approximate visual ratio:
65% ivory/paper, 20% graphite, 10% petrol, 5% copper.

Avoid: neon, purple AI gradients, bright SaaS blue, glassmorphism.

## Typography

Display / thinking: Literata or another strong Cyrillic editorial serif.

UI / systems: Manrope or another clean modern Cyrillic sans-serif.

Semantic contrast:
- serif = thought / human / meaning
- sans-serif = system / data / navigation / tool

Desktop H1: 68–86px range.
Main body: 18–20px.
Limit line length to approx. 65–70 characters.

## Layout

- desktop canvas reference 1440px
- 12-column grid
- asymmetric editorial compositions
- generous negative space
- avoid repeated 3-card / 4-card SaaS sections
- thin 1px rules
- restrained 3–5px button radius

## Signature graphic language

MAP OF RELATIONS:
- nodes
- thin connections
- branches
- incomplete relationships
- annotations
- coordinates / small technical labels
- open fields

The graphics should feel editorial, not like an IT network diagram.

## Interaction

Slow, nearly invisible.

Examples:
- relations reveal during scroll
- a small number of connections draw in the hero
- hover reveals adjacent concepts
- 150–300ms UI transitions
- respect prefers-reduced-motion

Avoid cursor gimmicks, blobs, noisy parallax.

## Photography

Natural daylight, editorial, European, tactile.

Materials: stone, wood, paper, architecture, working environment.

Do not use: stock businesswoman with laptop, corporate portraits, glamour, coaching imagery, mystical imagery.

## Prohibited visual clichés

- robots
- AI brains
- chips
- sparkles
- rockets
- lightbulbs
- generic targets
- neon networks
- mystical runes/tarot/crystals
- pill-button-heavy layouts
- rounded card grids everywhere
