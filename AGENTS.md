# AGENTS.md — Instructions for Codex

You are implementing the personal professional site of Tatiana Miroshina.

Before making visual or content changes, read:
- BRAND.md
- DESIGN_SYSTEM.md
- CONTENT.md

## Non-negotiable design constraints

Do not turn the site into:
- a SaaS landing page
- an AI startup
- a digital agency
- coaching / infobusiness
- luxury personal branding
- an esoteric website

Do not add:
- purple or blue AI gradients
- glassmorphism
- glowing blobs
- robots
- AI brain imagery
- sparkles
- generic card grids
- giant pill buttons
- decorative shadows without purpose

## Design decision hierarchy

When uncertain, choose in this order:
1. conceptual clarity
2. editorial hierarchy
3. whitespace and rhythm
4. visual distinctiveness
5. interaction
6. decoration

## Core visual idea

The signature motif is a map of relationships.

The page should visually express:
FIELD → RELATIONS → STRUCTURE → POSSIBLE ACTION

Do not represent the work as CHAOS → ORDER.

## Implementation principles

- semantic HTML
- responsive from 1440px down to 390px
- accessible contrast
- keyboard-visible focus states
- prefers-reduced-motion
- avoid unnecessary dependencies
- use SVG/CSS for system-map visuals when possible
- keep components reusable for future pages

## First iteration goal

Make the homepage feel designed, not scaffolded.

After implementation, inspect the page visually and correct:
- weak hierarchy
- awkward line lengths
- excessive symmetry
- cramped spacing
- repetitive cards
- mobile stacking that loses the editorial character

Do not rewrite the core positioning without a specific instruction.
